# Portfolio React - Samia Boutezrout

Portfolio professionnel Support IT N1/N2 avec :

- React + Vite
- Tailwind CSS v3 compatible PostCSS
- Framer Motion
- Lucide React icons
- Mode clair / sombre
- Photo dans la première page
- CV dans `public/CV-Samia-Boutezrout.pdf`

## Lancer le projet

Dans PowerShell :

```powershell
cd C:\Users\BOUTE\OneDrive\Desktop\samia-support-portfolio-final
& "C:\Program Files\nodejs\npm.cmd" install
& "C:\Program Files\nodejs\npm.cmd" run dev
```

Ou dans CMD :

```cmd
cd C:\Users\BOUTE\OneDrive\Desktop\samia-support-portfolio-final
npm install
npm run dev
```

Puis ouvrir le lien affiché, souvent : `http://localhost:5173`
